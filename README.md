# Snake

Ein Snake-Spiel für Tablet und Browser – eine einzige HTML-Datei, keine Installation.

**Spielen:** https://visionthink.github.io/snake/

- Steuerung per Wischen, Pfeiltasten auf dem Bildschirm oder Tastatur
- Drei Geschwindigkeiten, optional „Durch Wände gehen“
- Der Rekord wird auf dem Gerät gespeichert
